**SOLMAR HEAT** — an original open-world crime game set in Solmar City, a sun-soaked coastal city. Explore on foot and by car, steal vehicles, outrun the police as your HEAT level rises, and pull off the Meridian Job across five story missions. Built with three.js as plain static files — no network, no build step. All city, characters, vehicles, story, art, and sound are original works made for this game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static file server and open `index.html`.
